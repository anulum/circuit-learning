# Circuit Learning

This repository is preparing the records and rules by which models that help design circuits are studied, graded, promoted and rolled back, as the learning application of the circuit design process built on DIRECTOR-AI. It is not SC-NC Learn, which trains spiking networks on chip. Its current executable surface is repository validation tooling. It has no model inventory, grader bundle, study, promotion record or registered record format, and no training, study or promotion has been run.

Circuit Learning is part of the **SC Neuromorphic Computing Systems** group (SC-NEUROMORPHIC-COMPUTING-SYSTEMS). The [group and project map](https://github.com/anulum/sc-neurocore/blob/main/docs/ecosystem.md) shows the whole programme and where this repository sits in it.

Every operation keeps a no-model path, a model never grades itself, and a verifier or a person, never a model, decides a verdict.

Read [Architecture](ARCHITECTURE.md), [validation tooling](validation-tooling.md), [data boundaries](THREAT_MODEL.md) and the [repository boundary decision](adr/0001-repository-boundary.md).
